# Ticket Booking Calculator

A simple Python program that calculates the total cost of booking tickets. It runs in the terminal.

## Features
- Enter the number of tickets you want to book
- select your ticket tye
- Calculates the total price automatically
- Gives discount to applicable members

## Built with
- Python
- arithmetic operations
- true/false values
- If-else statements

## How to run it
1. Install Python from python.org
2. Download `ticket_booking_calculator.py` from this repository
3. Open a terminal in the same folder and run:
   `python ticket_booking_calculator.py`
4. Follow the instructions on screen

- How to make decisions in a program with if-else statements
